# Conventions

- **All folder and file names are lower kebab-case** (`research-jobs`, `harvard-chemistry.json`). No spaces, no capitals, no underscores.
- Every lab `id` is kebab-case: `<institution>-<unit>-<pi-profile-slug>`, e.g. `harvard-chemistry-theodore-betley`.
- One file per source unit in `data/sources/<source-id>.json`; `data/labs.json` and `data/labs.csv` are generated by `scripts/build.py` and never edited by hand.
- Record only what a page shows. Unknown is `null`, never a guess. Say what could not be read in `notes`.
- Record the date each source was checked (`checked_on`).
